AI 기반 발주 예측 시스템

외부 판매 플랫폼과 자사 판매·재고 데이터를 연계하여 상품별 판매 현황을 조회하고, 수요 예측 및 발주 판단에 활용하는 시스템을 구축한 공동 개발 프로젝트입니다.

공동 개발PythonFastAPIPostgreSQLProphetOpenAI API

01. 프로젝트 개요와 개인 기여

프로젝트 목적

외부 플랫폼과 자사 판매 데이터를 통합하고, 상품별 판매 추이 및 예측 정보를 발주 판단에 활용할 수 있도록 데이터 처리 및 연계 기능을 구현했습니다.

참여 형태

공동 개발. 시스템 전체를 단독 개발한 것으로 표현하지 않으며 아래 담당 기능을 중심으로 개인 기여도를 설명합니다.

직접 담당한 기능

  • 외부 판매 데이터 수집 및 정제
  • 상품코드·품번 기준 상품 데이터 매칭 및 표준화
  • PostgreSQL 데이터베이스 연동
  • FastAPI 기반 데이터 조회·처리 API 개발
  • Prophet 기반 수요 예측 기능 개발
  • OpenAI API 연동 기능 개발
  • 시스템 테스트 및 운영 업무

02. 시스템 구성

이력서에 기재된 기능을 기준으로 단순화한 개념적 데이터 흐름입니다. 실제 배포 구성 및 모듈 간 호출 순서를 그대로 재현한 설계도는 아닙니다.

외부 플랫폼·판매 데이터→Python 수집·정제·상품 매칭→PostgreSQL→FastAPI 데이터 제공
판매 이력→Prophet 수요 예측→발주 판단 관련 기능
상품·예측 정보→OpenAI API 연동→정보 요약·질의응답

03. 기술 구현 내용

데이터 수집·정제

외부 패션 플랫폼과 자사 판매 데이터를 수집·정제하고 채널별 형식 차이를 처리했습니다.

상품 매칭·표준화

상품코드 및 품번을 기준으로 서로 다른 채널의 상품 정보를 매칭하고 분석에 활용할 수 있는 형태로 표준화했습니다.

PostgreSQL 연동

PostgreSQL 데이터베이스와 백엔드 데이터 처리 기능을 연계했습니다. 이력서에는 SQLAlchemy 기반 모델·조회 로직 구현 경험이 기재되어 있습니다.

FastAPI API

상품·판매·재고·예측 데이터를 조회하고 처리하기 위한 API 개발을 담당했습니다.

Prophet 예측 기능

상품별 과거 판매 데이터를 활용한 수요 예측 기능을 개발했습니다. 예측 정확도와 검증 지표는 현재 확인된 자료에 없어 기재하지 않았습니다.

OpenAI API 연동

예측 결과 요약 및 상품 현황 질의응답 기능에 OpenAI API를 연계했습니다. RAG나 AI Agent를 구현했다고 주장하지 않습니다.

테스트·운영

시스템 테스트와 운영 업무를 수행했습니다. 세부 테스트 체계나 운영 지표는 확인 후 추가할 예정입니다.

04. 데이터 처리상의 주요 과제

채널별 상품 식별 기준 차이

서로 다른 판매 채널의 상품 정보를 연결해야 하는 과제에 대해 상품코드·품번 기반 매칭 및 표준화 기능을 구현했습니다.

수집 데이터의 누락·실패 대응

프로젝트에는 누락 기간 탐지 및 실패 데이터 재처리 기능이 포함되어 있습니다. 해당 기능의 개인별 담당 범위 및 구체적인 장애 해결 사례는 추가 확인이 필요합니다.

사례 작성 원칙

확인되지 않은 오류 메시지, 장애 원인, 성능 개선 수치, 처리 건수는 기재하지 않았습니다. 실제로 경험한 사례가 확인되면 문제 → 분석 → 조치 → 결과 순서로 추가할 수 있습니다.

05. 프로젝트 결과 및 보완 예정 내용

외부 플랫폼 및 자사 데이터의 통합 처리, 상품별 판매·재고·예측 정보 조회, 수요 예측과 생성형 AI API 연계 등 이력서에 기재된 기능을 구현한 프로젝트입니다.

  • 확인된 개인 기여: 데이터 수집·정제, 매칭·표준화, DB 연동, API, 수요 예측, OpenAI API 연동, 테스트·운영
  • 추가 기재 예정: 실제 API 예시, 익명화한 데이터 스키마, 본인이 해결한 장애 사례, 검증 가능한 처리량 또는 성과

고객사 내부 코드, 계정 정보 및 실제 운영 데이터는 공개하지 않습니다.
