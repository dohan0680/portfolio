# 이도한 Portfolio

Business Automation / Python / RPA Developer 포트폴리오입니다.

## 핵심 방향

- 현업 업무 분석 및 자동화 범위 정의
- Brity RPA 기반 웹·ERP·Excel 자동화
- Python 기반 데이터 처리 및 검증
- FastAPI / SQLAlchemy / PostgreSQL 기반 백엔드 개발
- Prophet / OpenAI API를 활용한 AI 기능 연동
- 구축 이후 운영·장애분석·개선까지 End-to-End 경험

## Featured Projects

### 1. AI 기반 발주 예측 시스템
Python, FastAPI, SQLAlchemy, PostgreSQL, Prophet, OpenAI API를 활용하여 외부 판매 플랫폼과 자사 판매·재고 데이터를 통합하고 수요예측 및 발주수량 산정 기능을 구현했습니다.

### 2. 식품·바이오 기업 발주 자동화
거래처별 상이한 발주 파일과 입력 규칙을 표준화하고, 상품별 박스입수량·출고가능수량·예외상품·단종상품 등의 업무 규칙을 자동화 로직으로 구현했습니다.

### 3. 4대보험 경정청구 자동화
급여대장, 원천징수, 건강보험, 고용정보 데이터를 근로자 기준으로 통합하여 검증·대상자 판정·수당 집계·결과 파일 생성까지 자동화했습니다.

## Tech Stack

- Automation: Brity RPA, Selenium, XPath, DOM
- Backend: Python, FastAPI, SQLAlchemy, REST API
- Database: PostgreSQL, SQL, MSSQL
- Data: Pandas, openpyxl, Excel/CSV Processing
- AI: Prophet, OpenAI API
- Web Logic: JavaScript

포트폴리오 내 고객사명과 내부정보는 익명화했으며, 실제 운영 데이터·계정정보·내부 소스코드는 공개하지 않습니다.

## Run locally

정적 사이트이므로 별도 빌드가 필요하지 않습니다.

```bash
python -m http.server 8000
```

이후 `http://localhost:8000`으로 접속합니다.
